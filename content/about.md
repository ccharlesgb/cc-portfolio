## dbt-dry-run

I currently maintain a python package called [dbt-dry-run](https://github.com/autotraderuk/dbt-dry-run) which is a tool for validating that a dbt project can run successfully without querying any data. This allows you to validate thousands of models very quickly and for free! This is useful in CI/CD and also running locally. I'm really proud of this project and it is being used in production by a number of companies.
